description

Created in my subject iOS Industry Studio, my team and I worked collaboratively with our clients at the Human Augmentation Lab to create a game to test user's spatial awareness through the use of audio pings. This project was created with the intention of helping the application of spatial audio in both games and real-life scenarios for blind and visually impaired users and players.

Learning more about how to help a group with a problem and learning to work alongside a client was an extremely valuable experience for me. I also had to learn to work on a project developed for augmented reality (AR) which was very challenging due to limited documentation available. This project involved a lot of experimentation, many road blocks, but ultimately ended up being very rewarding.

I helped design a way for users to navigate UI through custom gestures by creating a node-based system for the UI, where the UI formed a tree-like structure to allow the users to step through different options and step into different options. This design was important to prevent cognitive overload and help users navigate the UI efficiently without visual support.

A feature that I also worked on, which unfortunately did not make it into the final build, was the surface detection system which involved spawning different moles onto surfaces in the real world environment.
