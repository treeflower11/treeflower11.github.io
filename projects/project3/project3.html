description

First-year project for subject Game Design Methodologies. Worked alongside 4 group members to develop a 2D platformer where a princess uses her shapeshifting capabilities to save different kinds of animals from evil scientists.

technical details

Language: C#

Game Engine: Unity

contributions
  • Programmed the player shapeshifting system foundations to allow group members to add their own shapeshifts and game mechanics such as sleeping and barking for the dog shapeshift.
  • Designed the second level incorporating previous game mechanics and the new dog shapeshift's mechanics based around moving the enemy.
